1-1ストーリー

ある日、310王国にて――

平和なこの王国に突如あらわれたボスクッパに、王国の力の源であるスターパワーを奪われてしまった。

スターパワーを失ったこの王国は、あと少しで力を失ってしまう……。頼れるのは、勇気ある挑戦者――そう、あなただけ。

教室内に用意された4つのミニゲームをクリアして、クッパの手下たちからスターパワーを取り返そう！

スターパワー奪還を目指して、いざ冒険へ！

1-3ミニゲーム紹介

教室では4つのミニゲームが待っている。好きなゲームに挑戦しよう（各ゲーム所要 約2〜3分）

GAME 1

よっ氏のたまご転がし

よっ氏のたまごを崖に落とさないように転がして、ゴールまで運ぼう！

  • 制限時間 ーー秒
  • 難易度：ふつう
  • 目標：落とさずにゴールまで運べればクリア
GAME 2

ぱっ君の玉入れ

ぱっ君の口の中をめがけて玉を投げまくろう！口の中に入れば得点アップ！

  • 挑戦回数：ーー投
  • 難易度：かんたん
  • 目標スコア：ーー球以上入ればクリア
GAME 3

アイテムカード覚え

机に置かれたアイテムのカードの位置を覚えて、同じアイテムをめくっていこう！

  • 挑戦回数：1回ならやり直しOK
  • 難易度：むずかしい
  • 目標スコア：ーーペア見つけられればクリア
GAME 4

キャラクター釣り

プールの中から、310オリジナルキャラクターたちを釣り上げよう！キャラクターによってポイントが違うかも...？？

  • 挑戦回数：1回
  • 難易度：ふつう
  • 目標：ーー点以上獲得でクリア

ゲームクリアで「ーーーーー」プレゼント！ 4枚集めるとスペシャル賞品がゲットできるかも...
